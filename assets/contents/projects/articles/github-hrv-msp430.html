HRV Monitor Demo - MSP430

The MSP430-side code for a real-time heart-rate-variability monitoring demo with PPG sensors. It can run standalone or cooperate with the Raspberry Pi display-side repository.

Highlights

  • Targets embedded HRV monitoring with PPG sensor input.
  • Pairs with the Pi-side repository for real-time result display.
  • Connects directly to the broader PPG and HRV research line.
