PPG + ACC Data Acquisition

A compact repository for PPG and accelerometer data acquisition work. The public README is minimal, but the project name and context connect it to physiological sensing and HRV model development.

Highlights

  • Focuses on collecting PPG and accelerometer signals.
  • Supports the data side of wearable and embedded health-sensing workflows.
  • Complements the HRV monitoring and PPG-based prediction projects.
