TinyRunners C Code

The deployment-side C code for the TinyRunners TinyML project, targeting STM32 board deployment through MDK5 and Cube-AI workflows.

Highlights

  • Stores C source code for deploying a TinyML model on STM32.
  • Documents MDK5 import, target configuration, compilation, and board download steps.
  • Pairs with the Python training repository for the 2022 TinyML Design Contest.
