DistriLearn

A distributed learning and real-time intrusion detection research repository connected to the IEEE UIC 2022 paper on lightweight collaborative inferencing for IoT networks.

Highlights

  • Stores scripts, tutorials, data, and deployment notes for distributed learning experiments.
  • Uses Dask scheduler and worker nodes for cluster-style execution.
  • Includes model organization for CIC-IDS-2017, CSE-CIC-IDS-2018, and combined intrusion-detection datasets.
  • Supports both scikit-learn models and PyTorch neural-network models through configurable loading paths.
