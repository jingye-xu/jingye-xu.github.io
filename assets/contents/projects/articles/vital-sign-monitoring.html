Vital Sign Monitoring

A PPG-based heart-rate and heart-rate-variability research line focused on efficient sensing, robust estimation, and embedded deployment. The work spans dataset construction, signal-processing and machine-learning fusion, and resource-aware model optimization for constrained devices.

Highlights

  • Designed and built a multi-channel, multi-scenario, multi-placement PPG dataset for HRV studies.
  • Proposed a compound HRV estimation framework integrating signal processing with machine learning.
  • Achieved HRV estimation errors as low as 3.5% with sub-MB model sizes suitable for embedded and medical-grade devices.
  • Developed UP-RaNN, reducing neural architecture search time by up to 10 times and power consumption by up to 22% while maintaining more than 94% accuracy.

Research Contributions

The project addresses the gap between accurate physiological sensing and practical embedded deployment. It combines efficient sensor sampling, lightweight learning models, and resource-aware optimization so HR and HRV estimation can run on constrained MCUs and wearable-class devices.

Related publications include A Comprehensive PPG-based Dataset for HR/HRV Studies (ICHI 2025), Real-time Intelligent On-device Monitoring of Heart Rate Variability with PPG Sensors (JSA 2024), Efficient and Direct Inference of Heart Rate Variability using Both Signal Processing and Machine Learning (CHASE 2023), and PPG-Based Heart Rate Estimation with Efficient Sensor Sampling and Learning Models (ICESS 2022).
