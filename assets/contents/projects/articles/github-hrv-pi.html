HRV Monitor Demo - Pi

The Raspberry Pi side of a real-time HRV monitoring demo, including display hardware setup, SPI wiring, PPG sensor notes, and Pi-to-display integration.

Highlights

  • Documents a 2-inch LCD display module with SPI interface and ST7789 driver.
  • Includes wiring tables and hardware notes for Raspberry Pi 4B integration.
  • Works with the MSP430-side HRV monitoring code for end-to-end display.
