Autonomous Driving System

A low-cost indoor assistive-driving system that enables hands-free power wheelchair navigation using smartphone-based perception and real-time machine-learning inference. The system was designed for existing power wheelchairs without requiring major hardware modification.

Highlights

  • Built a smartphone-driven prototype using a customized ResNet model to generate real-time indoor navigation commands from camera imagery.
  • Engineered an Android app with TensorFlow Lite-optimized CPU, GPU, and TPU inference paths.
  • Achieved up to 25 FPS real-time inference with seamless command transmission to the wheelchair.
  • Validated an end-to-end prototype on a Pixel 6 smartphone and mobile robot platform for hallway and corridor navigation.

Research Contributions

The project translates autonomous-driving ideas into an accessibility-focused indoor mobility system. It emphasizes low deployment cost, real-time inference, reduced-attention operation, and compatibility with commodity smartphones and existing mobility platforms.

Related publications include An Intelligent Assistive Driving Solution Based on Smartphone for Power Wheelchair Mobility (Journal of Systems Architecture, 2024) and A Vision-based Low-cost Power Wheelchair Assistive Driving System for Smartphones (ICESS 2022).
